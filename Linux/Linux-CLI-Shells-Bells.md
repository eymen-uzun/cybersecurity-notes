This room helped me improve my Linux command-line skills by solving practical tasks in a Linux environment.

## Skills Learned

- Linux command-line navigation

```bash
find

```

## What I Learned

- How to navigate the Linux file system efficiently.
- How to create, move, copy, and delete files.
- How to search for files and specific text.
- Why the Linux command line is an essential skill in cybersecurity.

---

## Key Takeaways

- The terminal is faster than a graphical interface for many tasks.
- Knowing basic Linux commands is important for penetration testing and system administration.
- Practice is the best way to become comfortable with the command line.
